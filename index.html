CHIP

Your holographic AI agent for the machine you already own. Streaming, tool-wielding, bilingual in PLAN and BUILD — powered by C++ and Rust cores compiled onto your hardware. Keyless. No cloud lock-in.

Get CHIP Source on GitHub
01 · The stack

Native where it counts

A thin Python agent loop shells out to native cores for the hot paths — no Electron, no Docker, no server farm. Your machine does the work.

⚡

SSE streaming

Token-by-token responses framed by a C++ SSE encoder, delivered over a lightweight HTTP server.

🔧

Tools & delegation

Real tools on your box — shell, files, system info — plus a built-in delegate that spawns sub-agents.

🗺️

PLAN / BUILD

Mode-aware agent. Sketches a plan first, then builds. No more one-shot wall-of-text.

🧠

Rust context budget

A std-only Rust token estimator trims conversation context to a 32k-token budget in one call.

🗣️

Voice

Speak to it and hear it speak back — browser-level mic capture and playback, server-side TTS.

🚀

TTS cache

C++ LRU with SHA-256 ETags: repeated audio is served in ~3 ms instead of a ~500 ms network round-trip (~156×).

🔒

Keyless by default

No secret ships in the repo. Paste your key into one constant or set an env var — yours, kept local.

🐧

Everywhere

Linux, Windows, macOS. C++ builds to .so/.dll/.dylib; the Rust core is pure std with zero deps.

# the whole stack, from one clone
$ git clone https://github.com/jaivardhanpandey66-create/chip-app.git
$ cd chip-app && ./install.sh
$ export OPENROUTER_API_KEY=sk-or-v1-…   # or: echo -n 'key' > ~/.config/chip/key
$ python3 chip_web.py # → http://127.0.0.1:8000

03 · The family

jarvis & john — siblings, not clones

The same engine, tuned for different rooms. Jarvis runs anywhere (Windows-ready), John is macOS-native with the system’s own voice.

🪟

jarvis — cross-platform

Keyless by default, Windows DLL loaders, port 8008. The daily driver.

$ cd jarvis && pip3 install --user openai
$ python3 jarvis_web.py   # → :8008
🍎

john — macOS-native

Speaks with the system say voice, reports real Mac telemetry, builds .dylib cores.

$ cd john && ./build.sh && ./build_rs.sh
$ python3 john_web.py      # → :8010
🐧

And of course — chip

The original: streaming agent, PLAN/BUILD, tools, voice, native cores.

$ python3 chip_web.py      # → http://127.0.0.1:8000
